# Code de conduite

MalinosLand est un lieu de partage. En participant (dans le jeu, sur GitHub ou ailleurs), tu
t’engages à :

- être bienveillant·e, patient·e et respectueux·se, quel que soit le niveau des autres ;
- accueillir les débutants et expliquer plutôt que juger ;
- critiquer les idées, jamais les personnes ;
- refuser le harcèlement, les discriminations, les contenus haineux ou sexuels, le spam ;
- respecter la vie privée des autres (pas de diffusion d’informations personnelles).

Les comportements contraires peuvent entraîner le masquage de messages, l’exclusion temporaire ou
définitive. Signalements : en privé auprès du responsable du projet.
